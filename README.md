## 🚀 Project Overview
PunkBuster is a long-standing anti-cheat engine used in multiplayer games. Although widely used, the official PunkBuster website suffers from outdated design, poor navigation, and unclear documentation.

Across Assignments 1, 2, and 3, our goal was to **identify usability issues, understand user needs, and redesign the entire PunkBuster experience** using strong HCI and UX methodologies.

This repository includes the full UX workflow — from **user research → low-fidelity wireframes → high-fidelity prototypes**.

# 📌 Assignment 1 – User Research & Contextual Inquiry
We used several UX research methods to understand how gamers, developers, and publishers interact with PunkBuster.

### Research Methods
- Contextual Inquiry  
- User Interviews  
- Task Observation  
- Persona Creation  
- Usability Issue Identification  
- Severity Ratings (H/M/L)

### Personas
- **Gamer** – interested in fair gameplay  
- **Game Developer** – integrates anti-cheat tools  
- **Publisher Representative** – checks updates & licenses

### Key Pain Points
- Outdated, cluttered interface  
- Poor navigation structure  
- Lack of a search function  
- Confusing license inquiry process  
- Missing or unclear developer documentation  
- Support options hard to find  
- Low visual hierarchy  
- Role-specific information not provided

### Outcome
A clear list of validated usability issues guided the redesign process. It ensured the entire workflow stayed user-centered.

---

# 🎨 Assignment 2 – Low-Fidelity Prototyping
We transformed user insights into **exploratory sketches and wireframes**, producing multiple UI versions for comparison.

### Designs Created (Multiple Variants)
- Home / Landing Page  
- Login & Signup  
- PB Setup & Download  
- Support & Contact Pages  
- FAQ  
- License Inquiry  
- Careers Page  
- Community Forum  
- Games Page  
- Press Releases & News  
- About Us

### Why Version 1 Was Selected Most Often
- Better visual flow  
- Clearer information hierarchy  
- Simplified navigation  
- Improved readability  
- More intuitive layouts

### 🎯 Result
A complete low-fidelity wireframe system serving as the structural foundation for our high-fidelity UI.

---

# Assignment 3 – High-Fidelity Prototyping
We developed polished, professional-grade, high-fidelity UI screens based on the selected low-fidelity designs.

### Key Improvements
- Modern, clean visual design  
- Consistent layouts and typography  
- Accessible color contrasts  
- Optimized navigation system  
- Responsive layout considerations  
- Structured content for gamers, developers & publishers  
- Streamlined support & licensing workflows  

### Before vs After
| Old PunkBuster | Redesigned PunkBuster |
|----------------|-----------------------|
| Outdated UI | Modern, clean interface |
| Confusing navigation | Clear and minimal menu |
| No search | Global search bar |
| Poor documentation | Visual guides & step-by-step instructions |
| Hard-to-use licensing | Streamlined license forms |
| Unorganized content | Logical structure + role-based sections |

### Final Deliverable
A fully interactive high-fidelity Figma prototype showcasing the new PunkBuster experience.
